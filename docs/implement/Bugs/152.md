### The cards

- **#152:** `blog-article.ts:197` applies `title: 'Post not found — HostelHive'` (noindex) for an unknown slug, in every language.
  - **AC:** `/ur/blog/no-such-post` has an Urdu not-found title; `/en/...` is unchanged.
  - Fix direction: an `seo.*` key through `i18n.translate` inside the existing effect, in all 18 locale files.
- **#144:** `GoogleAnalyticsService.bindRouter` (`google-analytics.service.ts:200-206`) queues a `page_view` on **every** `NavigationEnd`, including query-only `replaceUrl` navigations:
  - arriving on `/search` sends two views (the map writes its viewport, `search-map.ts:1756`);
  - every pan or filter change sends another;
  - the listing's `?review` clean-up sends another (`listing-detail.ts:950`).

  **AC:** arriving on `/en/search` sends exactly one `page_view`, and a pan sends none; a pushed navigation to a new search still sends one.
  - Narrow rule: skip when the navigation was `replaceUrl` **and** the pathname did not change (`router.lastSuccessfulNavigation()?.extras.replaceUrl` is set before `NavigationEnd`).
  - Pushed filter changes stay page views.
  - GA counts change from the deploy date, so record it.

### What the code shows beyond the cards

- **The blog-article head effect (`blog-article.ts:194-…`) is not gated on `LocaleStore.ready()`.** Today it only writes English. A translated not-found title read before the strings load would return the key, in the server render too, unless the effect reads `ready()` (as `home.ts` and `blog.ts` do).
- **A skipped navigation must not flush the pending view.** Today `queuePageView` flushes the previous pending view first (`:239`). If a same-path `replaceUrl` navigation simply returned early but still flushed, arriving on search would send the arrival view one macrotask early, before its head settled. The skip has to leave the pending view alone.
- **Other same-path `replaceUrl` writers:** admin roles, host invoices, rooms, tenants, utilities, billing invoices, moderator audit and media. All are console routes, so GA already sends nothing for them. The public ones are search (`search-map.ts:1578, 1652, 1756`) and the listing (`:950`).
- **Path-changing `replaceUrl` navigations still count:**
  - **lead-wall:** the post-login redirect (`lead-wall.ts:80`);
  - **confirm-invitation:** the redirect to `/` (`confirm-invitation.ts:130`).
  - **The language switch** is a push (`locale-store.ts`, `navigateByUrl` with no `replaceUrl`).

## Root cause (confirmed in Phase 5: every fix row fails on main and passes on the branch)

**`@angular/router` 21.2.9 facts** (`_router-chunk.mjs`):
- `lastSuccessfulNavigation` is set at `:3892`, just before `NavigationEnd` at `:3893`, so a subscriber sees the navigation that just ended, with its `extras`, `trigger` and `previousNavigation`.
- The **initial navigation** (`:4466-4470`) and **Back/Forward** (`popstate`, `:4237-4243`) both carry `replaceUrl: true`.
- A guard redirect becomes a new `imperative` navigation that inherits `replaceUrl` (`:4436-4451`).
- **So the card's "replaceUrl + same path" rule would also drop Back/Forward between same-path entries.** It must also require `trigger === 'imperative'` and a previous successful navigation. Both the PE and the PM found this independently.

## Plan

### Merged plan

1. **#152:**
   - Add `seo.postNotFoundTitle` ("Post not found — HostelHive", byte-identical) to all 18 files, like `seo.listingNotFoundTitle`.
   - The blog-article head effect gains `if (!this.locale.ready()) return;` (the D1 home/blog pattern), and its not-found branch translates the key.

2. **#144:**
   - A pure, exported `isSamePageRefinement(nav, url, serialize)` returns true only when `nav.trigger === 'imperative'`, `nav.extras.replaceUrl` is set, and `pagePath(prev.finalUrl)` equals `pagePath(url)`. `pagePath` is reused from `core/scroll-reset.ts`, and the locale stays in the comparison.
   - The `bindRouter` subscriber returns **before** `queuePageView`, so the skip doesn't flush, replace or re-locate the pending view.
   - Everything else is unchanged: pushes, Back/Forward, the first load and path changes all count.
3. **GA count change:** record it, with the deploy date, in the PR, the summary and the KB. The user adds a GA4 annotation.

### Product Manager (key content)

- **Who is hurt:**
  - **The GA reader:** search page views are inflated (at least 2 per arrival, plus 1 per pan). GA4 counts 2 or more views as an "engaged" session, so engagement is inflated and bounce understated for search traffic. Funnels from search look worse than they are, and "next page" paths are dominated by search → search.
  - **#152:** non-English visitors and share cards of dead blog links see an English title. Low severity (noindex).
- **ACs:**
  - **#152, 1–8:** ur and ar titles in the server HTML and the client; English byte-identical; never a raw key; the language switch on a not-found page; GA title translated; all 18 files; no regression on real posts.
  - **#144, 1–11:**
    - arrival = 1 view, whose `page_location` is the arrival URL and whose title is search's own;
    - pan or zoom = 0;
    - filter pushes (modal Apply, amenity toggle, a gender-landing Apply) = 1;
    - "search everywhere" on `/search` = 0 (a replace), from a landing page = 1;
    - a place pick or "Near me" = 1 (recenter and viewport = 0);
    - the `?review` clean-up = 0, and the listing's single view keeps its loaded title;
    - Back/Forward = 1 per step;
    - the language switch = 1;
    - a reload = 1;
    - a skip never touches the pending view;
    - path-changing replaces still count;
    - other events unchanged.
- **Out of scope (follow-up proposed):** `search_performed` fires on every pan's refetch, the same inflation at the top of the funnel. Proposal: a `trigger` parameter (arrival / filter / map / place).
- **What to tell the GA reader:** annotate the deploy date. Views and views per session drop, engagement rate drops and bounce rises for search landings (an artefact, not a regression), and funnel conversion after search rises. Sessions, users, entrances and custom events are unchanged. Compare only unaffected metrics across the date.

## Summary

**Area:** analytics (Google Analytics page views), SSR/SEO head titles, i18n.

**What changed:**
- **#144, GA page views count pages, not URL refinements.** `GoogleAnalyticsService` (`core/google-analytics/google-analytics.service.ts`) gains an exported `isSamePageRefinement`, checked in `bindRouter` **before** `queuePageView`, so a skip never touches the pending view. A navigation is skipped when either:
  - **(A)** the app itself replaced the URL on the same page (`trigger === 'imperative'`, `extras.replaceUrl`, same `pagePath` as the previous successful navigation): map pans, zooms and recenters, "Search everywhere" on `/search`, and the listing's `?review` clean-up; or
  - **(B)** only the `#fragment` changed: the blog contents links.
- **What still counts:**
  - pushes: filter Apply, an amenity toggle, a place pick, "Near me", the language switch;
  - Back/Forward;
  - the first load and reloads;
  - path changes.
