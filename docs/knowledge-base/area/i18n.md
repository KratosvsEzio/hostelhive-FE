# Internationalisation (i18n)

Runtime translation with Transloco across 18 locales. Every URL carries its language (`/en/…`, `/ur/…`). The active locale drives the strings, `<html lang dir>` and RTL layout. A per-country guess picks the starting language and currency until the visitor chooses. Money formatting lives in [dates, money and time zones](./dates-money-and-time-zones.md). `hreflang` and the sitemap live in [SSR, SEO and prerender](./ssr-seo-and-prerender.md).

## Where it lives
- `apps/web/src/app/core/i18n/locales.ts` — `LOCALES` (code, endonym, English name, `dir`, flag, `translated`, and a required `ogLocale`, the Open Graph code `Seo` writes as `og:locale`, kept by hand because some differ from `code_COUNTRY`: Arabic is `ar_AR`), `DEFAULT_LOCALE = 'en'`, and the URL helpers `splitLocale`, `withLocale`, `hasLocalePrefix`, `routePath`, `localeAlternates`.
- `apps/web/src/app/core/i18n/provide-i18n.ts` — `provideI18n()` (Transloco config, `HttpTranslationLoader`, and `HH_LINK_LOCALISER` for library links).
- `apps/web/src/app/core/i18n/fs-translation-loader.ts` — server-only loader that reads the JSON off disk. Swapped in by `apps/web/src/app/app.config.server.ts`.
- `apps/web/src/app/core/i18n/locale-store.ts` — `LocaleStore`: `active`, `dir`, `ready`, `apply`, `switchTo`, `storedPreference`, `userChoice`. localStorage keys `hh.locale` and `hh.locale.chosen`.
- `apps/web/src/app/core/i18n/locale-sync.ts` — `LocaleSync.start()` (app initializer). It reads the entry URL from `PlatformLocation`, then follows `NavigationEnd`.
- `apps/web/src/app/core/i18n/locale-prefix-matcher.ts`, `apps/web/src/app/core/i18n/keep-locale.ts` — routing: a `:locale` tree matched only for known codes, and a bare tree whose `keepLocale` guard redirects to the prefixed URL (wired in `apps/web/src/app/app.routes.ts`).
- `apps/web/src/app/core/i18n/locale-link.ts`, `apps/web/src/app/core/i18n/locale-commands.ts` — `LocaleLink` (`a[routerLink]`) and `localiseCommands`, which prefix absolute links with the active locale.
- `apps/web/src/app/core/i18n/language-switcher.ts` — `hh-language-switcher`.
- `apps/web/src/app/core/i18n/provide-i18n-testing.ts` — `provideI18nTesting()` for app specs (keys resolve to themselves). The library equivalent is `lib/src/testing/provide-transloco-testing.ts`.
- `apps/web/public/i18n/` — `apps/web/public/i18n/en.json` plus 17 more.
- `apps/web/src/app/core/geo/country-preferences.ts` — `localeForCountry` / `currencyForCountry` tables. `apps/web/src/app/core/geo/geo-preference.ts` — `GeoPreference` (IP country lookup, applies the guesses). `apps/web/src/app/core/preferences/currency-preference.ts` — `CurrencyPreference`.
- `tools/i18n-check.mjs`, `tools/i18n-coverage.mjs`.

## How it works
- **Config.** `availableLangs` = all 18 codes; default and fallback are both `en`. `missingHandler` logs only in dev and falls back to English (`apps/web/src/app/core/i18n/provide-i18n.ts`).
- **Loading.** The browser fetches `/i18n/<lang>.json`. SSR reads browser/i18n beside the server bundle, or `apps/web/public/i18n` under `ng serve`, and registers the read with `PendingTasks` so the page is not serialized blank.
- **URL is the truth.** `LocaleSync` applies the URL's locale. `keepLocale` gives an unprefixed URL the active locale (mid-session) or the stored preference (on arrival). `LocaleLink` rewrites template links. Library components go through `HH_LINK_LOCALISER`.
- **Switching.** `LocaleStore.switchTo(code)` records the choice (`hh.locale.chosen`), applies `lang`/`dir` to `<html>`, and navigates to the same path under the new prefix with the query kept.
- **Country guess.** `GeoPreference` asks Cloudflare trace and api.country.is concurrently (5 s total budget). It maps the country to a language and currency only for the halves the visitor has not chosen, and the language half stands down when the URL named a language.
- **Locales.** en, ur, ar, hi, zh, ja, fr, de, es, it, nl, sv, da, hu, ru, id, vi, pl. All 18 have `translated: true`, so all get `hreflang` alternates. `ur` and `ar` are `dir: 'rtl'`. RTL relies on Tailwind logical utilities (`ms-`/`me-`/`ps-`/`start-`…) plus the `[dir='rtl']` rules in `apps/web/src/global.css`, which flip only arrow and chevron icons. Script-positioned overlays have to follow direction themselves. `[hhTooltip]` placement `end` reads `<html dir>` when it opens. In RTL it pins the bubble by `right`, not by `left` + `translateX(-100%)`. A `left` near the right edge squeezes the box into the remaining sliver, and the label wraps one word per line.
- **Key style.** Two levels, `group.key`, both camelCase. Groups are per feature or area (`common`, `hostNav`, `publicListing`, `listing`, `seo`, …). Parameters use `{{name}}`. Templates use `'group.key' | transloco`, and TypeScript uses `translate('group.key')`.

## Reuse, don't rebuild
- New copy: add the key to en.json (the gate) and to the other 17 files. Never hard-code English.
- Route `title:` values are label keys (see [ssr-seo-and-prerender](./ssr-seo-and-prerender.md)).
  - `core/i18n/route-title-locale-parity.spec.ts` checks every title key and the `seo.pageTitle` /
    `seo.adminPageTitle` templates across all 18 files. It covers presence, `{{page}}`, and "HostelHive"
    staying in Latin script.
  - `core/i18n/locale-files-testing.ts` has the shared loaders (`loadLocale`, `at`, `leaves`,
    `params`) for any new parity spec.
- A string read once in TypeScript (titles, meta, toasts): wait for `LocaleStore.ready()` or the first read returns the key.
- Links: plain absolute paths with `RouterLink` + `LocaleLink`. Navigation in code: router.navigate(['/x']) is fine, because `keepLocale` adds the prefix. Route checks: compare against `routePath(url)`, never the raw URL.
- Specs: `provideI18nTesting()` / `provideTranslocoTesting()`.

## Traps
- **`i18n-check` gates only en.json.** It runs as a `dependsOn` of `build` and `build-mobile` (`apps/web/project.json`), not of `serve`. It finds keys by regex: `'k' | transloco`, `translate('k')`, and bare `'group.x'` literals whose first segment names an existing group. A key assembled at runtime is invisible to it. A key missing from another locale fails nothing and silently renders English. `tools/i18n-coverage.mjs` reports the gap but is not gated anywhere.
- **Locale files: LF in git, CRLF on disk on this machine.** `git ls-files --eol` reports `i/lf w/crlf`. That comes from `core.autocrlf=true`; there is no `.gitattributes`. Each file round-trips exactly through `JSON.stringify(JSON.parse(text), null, 2) + '\n'` once line endings are normalised (all 18 verified). Writing LF back shows the file as modified with an empty `git diff`. Writing CRLF avoids the noise.
- **No English literal titles remain.** `seo.postNotFoundTitle` (PR #126) replaced the last one passed to `Seo.apply`. A head effect that translates anything must wait for `LocaleStore.ready()`: before it did, the blog not-found page served the description as the raw key `seo.defaultDescription`.
- **English-only groups.** 58 `userBookings` keys once existed only in en.json (Trello #153), and the search filter's property types and amenity chips were English literals in TypeScript (Trello #172). `core/i18n/seeker-locale-parity.spec.ts` now gates the whole `userBookings`, `filters` and `search` groups in all 18 files: presence, `{{param}}` names, and no copied English outside its per-file allowlist. Labels handed to `hh-dropdown` `[options]` go through a `LocaleStore.ready()`-gated `t()` (`SearchFilters`, `SearchFilterModal`), not the pipe.
- **Stale keys.** The 17 non-English files still carry an `accommodation` group that en.json dropped (1,491 keys vs 1,452).
- `.hh-ltr` (keep numbers and phones LTR inside RTL text) is defined in `apps/web/src/global.css` but used nowhere.
- Raw-DOM map popups and the Pakistan drill-down hard-code English (see [maps](./maps.md)).
- A Transloco event that writes a signal during render is refused and silently dropped. `LocaleStore` delays it a microtask on purpose (`apps/web/src/app/core/i18n/locale-store.ts`, 89caaf1).
- `apps/web/src/app/core/i18n/locales.ts` says to flip `translated` "as coverage reaches 100%". It is already true for all 18.
