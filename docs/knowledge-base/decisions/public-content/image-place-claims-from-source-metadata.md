# An image may name a place only if its source metadata names it, and a test enforces it

**Status:** Accepted
**Area:** [public-content](../../area/public-content.md)

## Context

The blog and the home page use stock and Commons photographs of Pakistani cities and the northern areas. Every blog image was reviewed by eye on a contact sheet and judged correct, yet fifteen captions still asserted a location the photographer never claimed — a minaret called Lahore because it was found by searching for Lahore, a lake named after the article it sat in. A reader who recognises the wrong city stops trusting the prices and advice too.

## Decision

- Each blog photograph's record in `apps/web/public/blog/CREDITS.json` keeps the photographer's own words as `sourceDescription`. Captions, alt text and file names may name a place only if that description names it; otherwise they describe what is visible.
- `blog-figures.spec.ts` ("never claims a place the photographer did not") checks every caption and alt against a list of place names, so the rule fails the build rather than relying on review.
- Credits are data: hero and city CREDITS.json are generated by the fetch tools with licence and source next to each URL, imported (not fetched) by `/credits` so the page renders on the server and cannot drift from the files.

## Alternatives rejected

- **Review by eye.** Demonstrably insufficient — it passed fifteen wrong captions (`blog-figures.spec.ts` comment).
- **Infer place from the search term, article or appearance.** That is exactly how the wrong captions arose (same comment).
- **Keep licences only in the generated CREDITS.json.** A re-run of the tool rewrote the file and wiped hand-recorded licences, so the licence lives beside the source URL in the tool (`tools/fetch-hero-images.mjs`).

## Consequences

- The guard covers the blog only. City tiles are named by their file (`/cities/<slug>.jpg`) and `landmark`; the six Commons entries have no `sourceDescription`, so their place claim rests on the linked Commons page and is not tested.
- A city tile should be a place, not a person: commit `5c77a6d` set aside a genuine Peshawar photograph because it centred on a person.
